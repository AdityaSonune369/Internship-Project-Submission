# Cybersecurity Internship Project Submission 🎓

This repository contains the complete portfolio of projects developed during my cybersecurity internship. The work spans from fundamental risk assessments for small businesses, to advanced enterprise network architecture concepts, and finally down to hands-on end-user threat simulations.

## Table of Contents

### 1. [Minor Project 1: SME Cybersecurity Risk Assessment & Mitigation](./minor_project_1)
A practical framework and quantitative assessment model specifically tailored for Small and Medium Enterprises (SMEs). This project includes a Python-based risk calculator and an interactive web dashboard to visualize security gaps.

### 2. [Minor Project 2: Zero Trust Architecture (ZTA) for Enterprise Security](./minor_project_2)
A simulated implementation of a Zero Trust Environment. I utilized Docker, Nginx (as an API Gateway), and Keycloak to strictly enforce identity verification and network segmentation, proving the effectiveness of the "Never Trust, Always Verify" principle.

### 3. [Major Project: Phishing Awareness Simulation](./Major%20Project)
A complete, safe-for-work simulated credential harvesting attack. Using a cloned Microsoft 365 login portal hosted on Vercel with a Flask backend, this project tracked click-through and compromise rates among a test group to highlight the critical role of human error in cybersecurity.
