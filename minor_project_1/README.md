# Minor Project 1: SME Cybersecurity Risk Assessment & Mitigation

This project addresses the critical gap between complex enterprise security standards and the practical, resource-constrained reality of Small and Medium Enterprises (SMEs).

## Overview

Based on the NIST Cybersecurity Framework, this project provides a quantitative assessment model to identify high-priority threats (such as phishing and ransomware) specific to SMEs. 

### Key Features:
- **Python Risk Calculator (`risk_calculator.py`):** An automated logic engine that replaces manual security audits for baseline checks, exporting a database of security history.
- **Interactive Web Dashboard:** A modern, human-centric interface (HTML/CSS/JS) providing real-time feedback and risk visualization for non-technical stakeholders.
- **Actionable Roadmap:** A detailed mitigation strategy focusing on Identity Control (MFA), Immutable Backups, Vulnerability Management, and Security Culture.

## Structure
- `Cybersecurity_Risk_Assessment_SMEs.pdf` / `.md`: The complete project report detailing methodology, risk tables, and case studies.
- `risk_calculator.py`: The Python script for calculating risk metrics.
- `index.html`, `style.css`, `script.js`: The interactive web dashboard for visualizing risk data.

## Usage
1. Run the Python script to perform a backend risk calculation.
2. Open `index.html` in your web browser to interact with the risk dashboard.
